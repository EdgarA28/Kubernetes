    00-03 · the chain of responsibility

    Who does what when you apply

    Every component talks only to the API server. When one stops, the chain stops at its step and resumes by itself when it returns. Pick a component to see what you would observe if it were down, where to look, and its reference card: how it runs, its ports, config, credentials, logs and how to restart it.

    How to study each module

    1. Object model firstYAML only sticks once you know what each field is for.
    2. YAML, then imperativeRebuild it with --dry-run=client -o yaml and compare.
    3. Watch it happenkubectl get events -w in a second terminal.
    4. Break itRead the symptom before you read the cause.
    5. Self-check closed-bookRetrieval, not recognition.
    6. Clean upRebuilding next time is the practice.
